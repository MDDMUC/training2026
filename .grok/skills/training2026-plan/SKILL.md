# Training 2026 methodology

## Before advising

1. Read `context/synthesis.md` first (integrated coaching position).
2. Then only the research file that matches the question:
   - Fingers, tissue, rehab → `context/research_camp4hp_nelson.md`
   - Max strength, benchmarks → `context/research_lattice.md`
   - Warm-up, mobility, running, knee → `context/research_hoopers_beta.md`
   - Periodization shape → `context/research_periodization.md` + `plan/00-overview.md`
   - No-hangs / collagen → `context/research_no_hangs_abrahamsson.md`
   - Extensors, shoulders, elbows → `context/research_antagonist_balance.md`
3. Check live numbers in the app / DB before quoting baselines. `context/jetgpt_dump.md` and the 2026-05-28 snapshot in `synthesis.md` go stale.
